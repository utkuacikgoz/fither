# FITHER brand assets

The mark is the pose-1 figure: a woman stretching into the F. Everything
here is generated by `scripts/generate-brand-assets.py` from one set of
variable-width bezier strokes — regenerate, never retouch by hand.

```
python3 scripts/generate-brand-assets.py
```

| File | Use |
|---|---|
| `fither-mark.svg` | The mark, sage on transparent — vector master |
| `fither-mark-bone.svg` | The mark, bone on transparent |
| `fither-icon.svg` | App icon master: bone mark on a sage square |
| `icon-1024/512/180/120/64.png` | Icon rasters (App Store, home screen, settings, spotlight) |
| `mark-sage-1024.png`, `mark-bone-1024.png` | Mark rasters on transparent |
| `lockup-sage-900x1100.png` | Mark + wordmark lockup |

The app's own copy lives at `app/assets/brand/mark.png` (640px, pure
white on transparent) and is written by the same script: the app tints it
to the theme's accent at render time, the same mechanism as the movement
figures, so one file is right in light and dark. `app/assets/icon.png` is
the 1024 icon.

Colours are the design tokens (`app/src/design/tokens.ts`): sage
`#5C6F5E`, bone `#FAF7F2`, gold `#B98A2F`. No other colour appears in the
brand set.
